## Cómo ejecutar el proyecto

Este proyecto utiliza Docker Compose para gestionar el entorno de desarrollo.

### Prerrequisitos
* Tener instalado [Docker Desktop](https://www.docker.com/products/docker-desktop).

### Pasos
1. Clona el repositorio.
2. Ejecuta el siguiente comando en la carpeta raíz para construir y levantar los contenedores:
   ```bash
   docker compose up --build
3. Accede a la aplicación en tu navegador en: `http://localhost:8080`.
